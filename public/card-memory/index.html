Card Memory

A playing card appears. Press SEEN if it has been shown before this run, or NEW if it has not. You have three lives; a wrong answer costs one. Once all 52 cards have appeared, a fresh deck joins the game — its cards carry one extra dot, so a dotted card counts as new even if its undotted twin already appeared.
